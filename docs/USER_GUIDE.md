# User Guide

## Send XLM by username

1. Open Padala in Chrome and unlock Freighter.
2. Connect the wallet and verify that the displayed account is correct.
3. Enter a federation address such as `merchant*padala.ph`.
4. Select **Resolve** and compare the returned account with the recipient.
5. Enter the XLM amount and an optional text memo.
6. Select **Send XLM**, review the Freighter prompt, and approve.
7. Save the transaction link shown after confirmation.

A successful transaction should appear in both Freighter history and a public
Stellar explorer.
