## Evidence checklist

- [ ] Production federation domain and SEP-2 response
- [ ] Public Stellar network configuration
- [ ] Public USDC issuer and recipient trustline
- [ ] External wallet signing flow
- [ ] Prepared transaction digest
- [ ] Confirmed Horizon transaction hash
- [ ] Stellar Expert link for each real transaction
- [ ] Reproducible deployment/runbook

When evidence exists, record only public identifiers here: network, account addresses, transaction hashes, ledger numbers, and explorer links. Never record secret keys, seed phrases, or bearer tokens.
